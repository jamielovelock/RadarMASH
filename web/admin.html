Airline logos

RadarMASH comes with no logos: they are the airlines' trademarks. To show them, give the address of a collection with {icao} where the airline's three-letter code goes, for example https://example.org/logos/{icao}.png. Clear the box to turn them off.

Control from elsewhere

Control key

Optional. With a key set, changing anything needs it: this page asks for it once, and other things on your network add &key=… to their requests. It is a simple lock for a home network, sent unencrypted like everything else here. Forgotten it? Press the radar's button five times quickly to remove it.

Control from elsewhere (a Stream Deck key, a home-automation rule): open an address such as . More than one thing can go in one address. Names: page (radar, weather, board, log, next), press (short, double, long), range (a number, or next), brightness, alert (look, home, test), select (a callsign), and any switch on this page by its name with on, off or toggle (for example map=toggle). The switch names are in /api/settings.
